Antonyhern16 Master Toggle project

WHAT THIS IS
A small Android Studio project with a single master ON/OFF button. The toggle state is saved between launches.

IMPORTANT LIMITATION
This is a starter project, not a modified copy of Antonyhern16-icon.apk. The button currently changes the app's saved profile state only; it does not automatically change Android or COD Mobile settings. Those require individual supported implementations and permissions.

BUILD ON ANDROID STUDIO
1. Extract this ZIP.
2. Open the extracted folder in Android Studio.
3. Allow Gradle sync to finish.
4. Select Build > Build Bundle(s) / APK(s) > Build APK(s).
5. The APK is usually at app/build/outputs/apk/debug/app-debug.apk.

For a custom APK matching the original app, the original Android Studio source project is needed.
